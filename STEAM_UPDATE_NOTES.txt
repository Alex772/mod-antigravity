[h2]🔧 Melhorias Técnicas[/h2]
[list]
[*] [b]PositionSyncCommand Expandido[/b] - Agora inclui dados de animação
[*] [b]Override Visual[/b] - Cliente recebe animação do Host a cada sync (0.5s)
[*] [b]HashedString Fix[/b] - Corrigido problema com nomes de animação
[/list]

[h2]📋 Como Funciona[/h2]
[list]
[*] Host executa animação (ex: cavar)
[*] A cada 0.5 segundos, posição + animação são enviados
[*] Cliente recebe e sobrepõe a animação visual
[*] Resultado: Duplicants fazem a mesma coisa em todos os computadores!
[/list]

[h2]🐛 Correções[/h2]
[list]
[*] Duplicants não ficam mais parados (idle) no cliente quando deveriam estar trabalhando
[*] Melhor consistência visual entre Host e Cliente
[/list]
